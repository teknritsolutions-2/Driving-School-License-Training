# ApexDrive Academy - Commercial Driving School & License Training Multi-Page HTML Template

**ApexDrive Academy** is a commercial-grade, multi-page HTML5 template designed specifically for driving schools, certified instructor academies, motorcycle training centers, and license preparation businesses.

---

## 🌟 Key Features

* **Built for the Driving School Niche**: Includes dual-control fleet showcases, certified instructor profiles, training stage journeys, 40-hour DMV progress tracking, manual transmission stick-shift modules, and license road test preparation.
* **Two Unique Home Pages**:
  * **Home Page 1**: Classic Driving Academy (Hero, animated statistics, course catalog, 4-step learner journey, instructor showcases, testimonials, and FAQs).
  * **Home Page 2**: Fast-Track License Journey (Interactive program matcher, accelerated track comparison, skill matrix, and instructor pairing).
* **Dedicated Student Dashboard** *(Strictly learner-focused — NO admin dashboard)*:
  * Overview with training hours progress (28/40 hrs completed vs. required)
  * Multi-step interactive lesson booking wizard
  * My Lessons status filtering (Upcoming, Completed, Cancelled)
  * Curriculum & Skills milestone breakdown
  * Instructor written feedback logs with scorecards
  * Printable / PDF-ready certified progress report
  * Student profile & notification settings
* **4 Display States Supported on All Pages**:
  * Light + LTR
  * Dark + LTR
  * Light + RTL
  * Dark + RTL
* **Modern Technical Stack**: HTML5, Bootstrap 5.3.3, Custom CSS Variables, ES6+ Vanilla JS, and Bootstrap Icons.
* **WCAG 2.1 AA Accessible**: High-contrast color palette, focus-visible outlines, skip links, semantic HTML5, and reduced motion queries.
* **SEO Optimized**: Unique meta titles, structured headings, OpenGraph tags, and semantic schema markup.

## 🚀 Quick Start

1. Clone or extract the project files.
2. Open `pages/index.html` directly in any modern browser.
3. For local HTTP server preview:
   ```bash
   python3 -m http.server 8080
   # Open http://localhost:8080/pages/index.html in your browser
   ```
