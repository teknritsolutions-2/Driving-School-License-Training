Installation & Setup Guide

Welcome to the ApexDrive Academy HTML template. This guide explains the project structure and how to run or deploy the template locally and on production servers.

2. Running the Template Locally

You can open any HTML file directly in your browser, or serve it via a local static web server:

# Using Python 3:
python3 -m http.server 8080

# Or using Node npx serve:
npx serve .

3. Production Deployment

ApexDrive is 100% static HTML5, CSS3, and modern Vanilla JS. You can deploy it to any static web host such as GitHub Pages, Netlify, Vercel, Cloudflare Pages, AWS S3, or Apache/Nginx by uploading the root directory.
