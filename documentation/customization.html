Customization & Integration Guide

Learn how to adapt the color palette, typography, form handlers, and hook up live booking or authentication APIs.

1. Customizing Colors via CSS Variables

All brand colors are controlled centrally in assets/css/style.css:

:root {
  --color-primary: #1d4ed8;       /* Primary Brand / Button Color */
  --color-accent: #f59e0b;        /* Signal Gold / Highlights */
  --color-secondary: #0f172a;     /* Deep Slate Navy */
  --color-success: #10b981;       /* Road Green / Passed Badges */
  --color-danger: #ef4444;        /* Stop Red / Error Alerts */
}

2. Typography & Google Fonts

ApexDrive uses Outfit for geometric display headers and Plus Jakarta Sans for body UI text. To change fonts, update the Google Fonts <link> in the <head> and update --font-primary in style.css.

3. Contact Form Backend Integration

The contact form in pages/contact.html is pre-configured for Formspree or Netlify Forms:

<!-- Formspree Option -->
<form action="https://formspree.io/f/YOUR_ENDPOINT_ID" method="POST">

<!-- Netlify Forms Option -->
<form name="contact" method="POST" data-netlify="true">

4. Lesson Booking API Integration

In assets/js/dashboard.js and pages/booking.html, the booking handler triggers an asynchronous confirmation. To connect to a live backend (e.g. Node/Express, Laravel, or Firebase): 

// Inside confirmBooking handler in assets/js/dashboard.js:
const response = await fetch('/api/v1/lessons/book', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify(bookingState)
});
const result = await response.json();
